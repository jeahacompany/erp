일평균 출고 = 기간 출고 ÷ 실제 영업일 수 (휴무일 제외) · 소진예상도 영업일 기준입니다.
권장발주 = 일평균 × (발주주기 + 리드타임) + 안전재고 − 현재고 − 발주중 수량. 발주주기 옆 *는 실제 입고 간격에서 자동 측정된 값, 리드타임 옆 ~는 시스템 기본값(매입처 관리에서 실제 값을 넣으면 정확해집니다).
"평소 1회 입고"와 비교해서 권장량이 훨씬 크면 평소 발주량으로는 다음 입고까지 못 버틴다는 뜻입니다.

행을 누르면 수정. 리드타임 · 발주방법 · 결제조건 세 가지가 채워지면 "작성완료"로 바뀝니다. 미완료부터 위에서부터 하나씩 채워주세요 — 리드타임이 채워질수록 발주 계산이 정확해집니다.

품목마다 어느 매입처에서 사오는지 지정합니다. 한 번 지정하면 발주서가 매입처별로 자동으로 묶입니다.

같은 상품인데 매입처만 다른 품목들을 묶어서 보여줍니다. 통합 재고·수요로 실제 상황을 판단하고, 단가 비교로 어디서 사는 게 이득인지 확인하세요. 자동으로 묶였고, 잘못 묶인 건 품목 관리에서 그룹을 바꾸면 됩니다.

발주서 생성에서 "발주 기록 + 복사"를 누르면 여기에 쌓입니다. 입고 예정일(발주일 + 매입처 리드타임)이 지나도 안 들어오면 지연으로 표시됩니다. 물건이 들어오면 "입고완료"를 눌러주세요.

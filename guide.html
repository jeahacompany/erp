⭐ 데이터 기준 — 이것부터 알고 시작하세요

모든 숫자는 "출고일(발송일)" 기준입니다.
주문이 들어온 날이 아니라, 실제로 물건이 창고에서 나간 날로 매출과 재고를 잡습니다.
항목기준 날짜이유
매출출고일물건이 나가야 확정 매출 (주문만으론 취소될 수 있음)
재고 차감출고일매출과 같은 날이어야 재고가 정확히 맞음
산지직송 매출출고일위와 동일
입고·마감재고물류 파일의 날짜물류사 기준이 최종 확정값
광고비집행일그날 실제로 쓴 돈 (매출과 1~2일 시차는 정상)
⚠ 중요: 주문일 기준으로 뽑은 자료(예: 채널 관리자 화면의 "일별 주문")와는 숫자가 다릅니다. 같은 날짜라도 주문 기준과 출고 기준은 수백 개씩 차이가 납니다 (밤늦은 주문이 다음날 나가니까요) — 틀린 게 아니라 세는 기준이 다른 것입니다. 회사 공식 숫자는 출고 기준이니, 다른 자료와 비교할 땐 기준부터 확인하세요.
✅ 그래서 매출 파일은 "그날 송장이 나간 건"만 담겨 있어야 합니다. 발주 프로그램에서 발송/출고 완료 기준으로 뽑아주세요.

📌 파일명 규칙 (중요!)

파일명에서 날짜를 자동으로 읽기 때문에, 규칙에 안 맞으면 업로드 자체가 안 됩니다.
  • 매출: 집에서먹자 8월 11일 매출.xlsx — 날짜 + "매출"
  • 물류: 집에서먹자 8월11일 출고,입고 12일 시작재고.xlsx — 날짜 + "출고,입고"
  • 테무: 0811 테무 1차 발주.xlsx — 날짜 + "테무"
  • 산지: 집에서먹자 8월 11일 매출 산지.xlsx — 날짜 + "산지"
⚠ 다운로드한 파일 이름이 다르면 이 규칙대로 이름을 바꾼 뒤 올리세요. 날짜를 손으로 고를 필요가 없어져서 실수가 사라집니다.

📅 매일 할 일 (순서대로)

1
매출(송장) 파일 올리기
왼쪽 메뉴 🧾 매출 업로드 → 왼쪽 큰 칸에 발주프로그램에서 받은 엑셀을 끌어다 놓기 → "송장 파일 감지"가 뜨면 출고(발송) 날짜를 확인하고 이 날짜로 반영 클릭
2
테무 파일 올리기 (있는 날만)
같은 화면의 보라색 칸(테무·그립 전용)에 테무 엑셀을 끌어다 놓기
⭐ 같은 날짜에 1차·2차·3차 파일이 여러 개면 반드시 한꺼번에 전부 선택해서 올리세요 (Ctrl 누르고 여러 개 클릭)
3
산지직송(위탁) 매출 올리기 (있는 날만)
같은 화면의 주황색 칸(산지직송)에 "매출 산지" 파일을 끌어다 놓기. 산지 상품은 우리 창고를 안 거치므로 재고에는 반영되지 않고, 매입가 기준 마진이 자동 계산됩니다. 여러 날짜를 한꺼번에 올려도 됩니다.
4
물류 파일 올리기 (출고·입고·시작재고)
왼쪽 메뉴 📤 마감 업로드 → 물류에서 받은 엑셀을 끌어다 놓기 → 미리보기 표에서 숫자 확인 → 기준일자를 그 파일의 날짜로 (예: "8월7일 출고,입고" 파일이면 8월 7일) → DB에 반영
4
"상품 연결 필요"가 뜨면
새로 팔기 시작한 상품이라는 뜻입니다. 어떤 우리 품목인지 알면 SKU를 검색해서 연결하고, 모르겠으면 그냥 두고 관리자에게 말하세요 — 나중에 연결해도 판매 기록은 자동으로 따라 들어갑니다.
⚠ 순서 지키기: 매출·테무 먼저 → 물류 파일은 마지막. 물류 파일이 그날의 최종 확정이에요.
⚠ 매출 파일을 다시 올렸다면, 그날 테무·그립도 다시 올려야 합니다. 송장 파일에는 테무·그립 결제금액이 비어 있어서, 매출 파일을 다시 올리면 그날 테무 매출액이 0으로 덮입니다. (수량은 남고 금액만 사라지므로 눈에 잘 안 띕니다 — 시스템이 데이터 점검에서 잡아줍니다.)
✅ 같은 파일을 실수로 두 번 올려도 괜찮습니다 (덮어쓰기라 중복 안 생김). 빠뜨린 날짜를 나중에 올려도 그 자리에 채워집니다.

✖️ 수량배수 — 가장 많이 틀리는 곳

상품을 연결할 때 수량배수 칸이 있습니다. 주문 1건이 나가면 창고에서 몇 개가 빠지는지를 적는 칸입니다.

옵션명수량배수이유
갈비살 200g11개 나감
갈비살 200g x 441건 주문에 4팩이 나감
갈비살 200g × 3팩3표시만 다를 뿐 같은 뜻
모듬곱창 960g (곱창+대창2+막창+염통)구성품마다 1 / 2 / 1 / 1세트는 [+구성품]으로 나눠서
⚠ 여기를 1로 두면 판매수량이 배수만큼 적게 잡힙니다. 그러면 원가가 낮게, 이익은 높게, 발주 권장량은 부족하게 나옵니다. 숫자 전체가 조용히 틀어지는 유일한 지점이라 가장 조심해야 합니다.
✅ 시스템이 옵션명에서 배수를 읽어 미리 채워 넣고 노란색으로 표시합니다. 맞는지만 확인하면 됩니다. 틀린 게 나중에 발견돼도 관리 → 데이터 점검에 "수량배수 누락 의심"으로 자동으로 뜹니다.

🧠 올리고 나서 확인하는 습관

  • 📊 한눈에 보기에서 "오늘의 브리핑" 읽기 — 발주할 것, 품절 위험을 시스템이 알려줍니다
  • 화면 위 "마감반영" 날짜가 오늘(또는 올린 날짜)로 바뀌었는지 확인
  • 숫자가 이상해 보이면 (재고가 마이너스, 매출이 0 등) 그대로 두고 바로 관리자에게 캡처해서 전달 — 억지로 다시 올리지 마세요

관리자는 여기에 하나 더: ⚙️ 관리 → 데이터 점검. 자료가 꼬였을 만한 곳 11가지를 자동으로 훑어 무엇이 왜 문제인지, 어떻게 고치는지까지 한 줄로 알려줍니다. 초록색이면 넘어가도 됩니다.

점검 항목왜 위험한가
수량배수 누락판매수량이 배수만큼 적게 잡혀 원가·발주가 전부 틀어짐
같은 날짜 중복 업로드서로 다른 파일이었다면 그날 숫자가 뒤바뀜
재고 마이너스입고 누락 또는 출고 이중반영
수량만 있고 매출액 0테무·그립 원본 미업로드 → 이익이 낮게 보임
매출↔물류 출고 불일치구성품·배수 연결 누락 (같은 수가 ± 짝이면 마감시각 이월이라 정상)
중복 상품 연결이모지만 다른 같은 상품이 2개 → 한쪽만 고치면 계속 옛날 값
원가·산지 매입가 미등록이익이 실제보다 크게 보임
매출/물류 한쪽만 있는 날그날부터 재고 또는 매출이 실제와 벌어짐

💬 불편한 게 있으면 그 자리에서 말해주세요

화면 오른쪽 아래에 항상 떠 있는 💬 요청하기 버튼을 누르세요. 쓰다가 불편한 것, 틀려 보이는 숫자, 있었으면 하는 기능 — 무엇이든 좋습니다.

  1. 화면은 자동으로 적힙니다. 어느 화면에서 눌렀는지 시스템이 알아서 넣습니다.
  2. 내용을 적습니다. 말투는 신경쓰지 마세요 — "발주서 글씨 작음" 이 정도면 알아듣습니다.
  3. 사진을 붙일 수 있습니다. 화면을 캡처한 뒤 Ctrl+V 로 붙여넣으면 끝입니다. 어디가 문제인지 그림판 등으로 표시해두면 더 좋습니다.
  4. 보내기. 대표님이 보고 승인하면 개발로 넘어갑니다.

❓ 자주 묻는 것

Q. 날짜를 잘못 선택해서 올렸어요
→ 같은 파일을 맞는 날짜로 다시 올리고, 관리자에게 잘못 올린 날짜를 알려주세요.

Q. "미등록 SKU"라고 떠요 (마감 업로드)
→ 물류에 새 상품이 생긴 것. 관리자에게 알려주면 품목 등록 후 다시 올리면 됩니다.

Q. 재고가 마이너스로 보여요
→ 입고 기록이 아직 안 들어온 것일 수 있어요. 그날 물류 파일을 올리면 대부분 자동으로 맞춰집니다. 그래도 마이너스면 관리자에게.

Q. 개인정보(고객 주소·전화)도 올라가나요?
→ 아니요. 파일 속 개인정보는 서버로 전송되지 않고, 날짜·상품·수량·금액 집계만 저장됩니다.
